# Assignment 15 – Promises and async/await with Local Data

This assignment covers JavaScript Promises, error handling, async/await, and local data.

## Questions

1. **Question 1:** Create a `checkMarks()` Promise that resolves when marks are between 0 and 100.
2. **Question 2:** Use the same Promise to reject invalid marks and display the error message.
3. **Question 3:** Use `async/await` and `try/catch` to handle valid and invalid marks.
4. **Question 4:** Create a `getUsers()` Promise that resolves after 100 milliseconds with local user data and display each user's name.

## Technologies Used
- HTML5
- JavaScript

All program outputs are displayed in the browser Developer Console.
