# Assignment 10 – Objects and Destructuring

This assignment covers JavaScript objects, property modification, array destructuring, and object destructuring.

## Questions

1. **Question 1:** Create a student object and update its marks.
2. **Question 2:** Extract array elements using array destructuring.
3. **Question 3:** Extract object properties using object destructuring.

## Technologies Used
- HTML5
- JavaScript (ES6)
