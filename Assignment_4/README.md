# Assignment 4 – Writing Functions

## Objective
To understand how to create and use JavaScript functions, arrow functions, parameters, and default parameter values.

## Questions

1. **Greeting Function:** Create a function `greet(name)` that returns a greeting message.
2. **Arrow Function:** Create an arrow function `square` that returns the square of a number.
3. **Function with Default Parameter:** Create `billWithTax(amount, taxRate)` with a default tax rate of 0.18 and calculate the final bill amount.
