# Assignment 13 – Reduce, Some, Every and Map

This assignment covers JavaScript array methods: `reduce()`, `some()`, `every()`, and `map()`.

## Questions

1. **Question 1:** Calculate the total of prices using the `reduce()` method.
2. **Question 2:** Use `some()` to check whether any mark is below 40 and `every()` to check whether all marks are at least 35.
3. **Question 3:** Use `map()` to add 5 to each mark and print both the updated and original arrays.
