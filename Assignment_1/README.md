# Assignment 1 – Your First JavaScript Script

## Objective
To understand the basics of JavaScript, including displaying output, declaring variables, and checking data types.

## Questions

1. **Hello from JavaScript:** Create an HTML page with a JavaScript script that prints `Hello from the script` in the browser console.
2. **Variables:** Declare a constant `schoolName` and a variable `year`. Print both values.
3. **Data Types:** Use `typeof` to display the data types of a string, a number, and a boolean.

## Technologies Used
- HTML
- JavaScript
