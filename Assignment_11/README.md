# Assignment 11 – Scope and Closures

This assignment covers JavaScript block scope, closures, and global scope.

## Questions

1. **Question 1:** Demonstrate block scope using variables.
2. **Question 2:** Create a counter function using closures.
3. **Question 3:** Access a global variable inside a function.
