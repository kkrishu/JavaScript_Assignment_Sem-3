# Assignment 5 – Arrays, Array Methods and Nested Arrays

This assignment covers JavaScript arrays, array properties, array methods, and nested arrays.

## Questions

1. **Question 1:** Find the length and first element of a marks array.
2. **Question 2:** Use `forEach()` to print all subjects.
3. **Question 3:** Use `filter()` to select marks greater than or equal to 60.
4. **Question 4:** Access an element from a nested array.

## Technologies Used
- HTML5
- JavaScript
