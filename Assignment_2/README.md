# Assignment 2 – Operators, Type Conversion and a Calculator

## Objective
To understand JavaScript arithmetic operators, type conversion, and conditional statements.

## Questions

1. **Arithmetic Operators:** Perform addition, subtraction, multiplication, and division using two numbers.
2. **Type Conversion:** Convert a string into a number and a number into a string, then perform the required operations.
3. **Simple Calculator:** Use `if...else if` statements to perform addition or subtraction based on the selected operator.
