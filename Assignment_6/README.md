# Assignment 6 – JSON Text

This assignment covers JSON conversion, parsing, and error handling in JavaScript.

## Questions

1. **Question 1:** Convert a JavaScript object into JSON text using `JSON.stringify()`.
2. **Question 2:** Convert JSON text into a JavaScript object using `JSON.parse()`.
3. **Question 3:** Handle invalid JSON using `try...catch`.

## Technologies Used
- HTML5
- JavaScript
- JSON

## Output
All program outputs are checked in the browser's Developer Console.

## Folder Structure
Each question has its own folder containing `index.html`, `script.js`, and `Output.png`.
