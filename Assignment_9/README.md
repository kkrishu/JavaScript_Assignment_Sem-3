# Assignment 9 – DOM, Validation, Storage and Quiz

This assignment covers DOM manipulation, form validation, browser localStorage, and interactive quiz functionality.

## Questions

1. **Question 1:** Change webpage heading text using DOM manipulation and a button click.
2. **Question 2:** Validate a name using a JavaScript function.
3. **Question 3:** Save and retrieve notes using localStorage.
4. **Question 4:** Create an interactive quiz using radio buttons.

## Technologies Used
- HTML5
- JavaScript
- DOM
- localStorage

## Output
DOM-based tasks are tested through webpage interactions. Program output is checked in the browser's Developer Console where applicable.

## Folder Structure
Each question has its own folder containing `index.html`, `script.js`, and `Output.png`.
