# Assignment 12 – Callbacks and Higher-Order Functions

This assignment covers JavaScript callbacks and higher-order functions.

## Questions

1. **Question 1:** Create an `applyTwice()` function that applies a callback function twice to a given value.
2. **Question 2:** Create a `formatMarks()` function that uses a callback to format marks.
3. **Question 3:** Create a `repeatAction()` function that executes a callback multiple times with the round number.

## Technologies Used
- HTML5
- JavaScript
