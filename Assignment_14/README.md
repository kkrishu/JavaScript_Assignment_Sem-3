# Assignment 14 – Timers and Intervals

This assignment covers JavaScript timers and interval methods.

## Questions

1. **Question 1:** Use `setTimeout()` to observe the execution order of Start, End, and Timer done.
2. **Question 2:** Use `clearTimeout()` to cancel a scheduled timer.
3. **Question 3:** Use `setInterval()` to print Tick and count every 200 milliseconds, and stop it using `clearInterval()` after three executions.
