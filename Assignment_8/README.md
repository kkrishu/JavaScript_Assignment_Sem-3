# Assignment 8 – Inheritance, Methods and Composition

This assignment covers JavaScript inheritance, class methods, and object composition.

## Questions

1. **Question 1:** Create Person and Teacher classes using inheritance.
2. **Question 2:** Create a Locker class with a PIN-checking method.
3. **Question 3:** Create Engine and Car classes using composition.

## Technologies Used
- HTML5
- JavaScript (ES6)
